# nichiji

`日時,内容` の CSV だけで動く、端末向けの小さな予定表です。calcurse をもっと素朴にしたもの、形式は [when](https://www.lightandmatter.com/when/when.html) 寄り。

- データは1ファイル2列(メモ欄を足すなら3列)の CSV。1ファイル = 1人か1台
- 画面は縦に流れる表1つだけ。行が日時、列がファイル。値のある行だけを並べる
- 時 → 日 → 月 → 年 は、同じ表の目盛りを粗くするだけ
- 曜日や祝日のような情報も、ただの CSV として列に並べる(nichiji 自身は曜日の名前を持たない)
- クイック登録: 内容だけ打って「未定」に入れ、日時はあとで決める
- 同じファイルの中で時間が重なる予定は入れられない
- 手を付けていない行・空行・`#` コメントは保存しても元のまま
- 画面・メッセージ・状態の書き方は英語(`[reserved]` `[running]` `[done]` `[canceled]`)。予定の中身は何語でもよい

## 入れ方

```sh
go install github.com/Mokkori-Tom/nichiji@latest
```

Go 製の単一バイナリで、Termux でもそのまま動く想定です。

## 使い方

```sh
nichiji 曜日.csv tom.csv hana.csv    # 列はこの順。書込先の既定は繰り返しだけのファイルを飛ばした最初のもの
nichiji ~/cal/                       # フォルダ内の *.csv を全部
nichiji ls [-days 14] [-past 0] [-u] [-memo] [ファイル...]   # 直近の予定を出して終わる(メモは * だけ、-memo で本文も)
nichiji ls -overdue [ファイル...]    # 終わりを過ぎた [reserved] [running] だけ。あれば終了コード 1
nichiji check [ファイル...]          # 手で書き換えたあとの確認: 読めない日時・重なり・LATE(ファイル名:行番号 付き)。あれば終了コード 1
nichiji find 歯医者 [ファイル...]     # 全期間・未定・繰り返しの内容とメモ欄を探す(ファイル名:行番号 付き)。無ければ終了コード 1
nichiji add 本を返す                 # 未定メモを1行追記
nichiji add -d '10/30 19:00' -m '駅前の店' 飲み会
nichiji set -f r.csv -match 語 -status running -end +30   # 1件を書き換える(下記)
nichiji done -f r.csv -match 語 -note '結果: x.out'      # 完了にして終わりを今に
nichiji free [-len 60] [-from 9:00] [-to 18:00] [-days 14] tom.csv hana.csv   # 全員の空き枠
nichiji notify [-before 10] [-cmd CMD] [-watch] [ファイル...]   # 通知(下記)
nichiji -now 2026-12-24 ...          # 今日を差し替える(確認用)
```

## 画面

```
nichiji hour  10-23 13:30
2026-10 曜日 tom
undated      本を返す
23      (金)
  09:00      定例 〜10:00
  10:00      定例 end
  13:00      研修 〜14:30 *
  14:30      研修 end
24      (土) 燃えないゴミ
tom  2026-10-23 13:00-14:30  研修
j/k move h/l column +/- scale Enter open Space memo …
```

- アジェンダ風(khal や gcalcli と同じ形): 月は `2026-10` の見出しの行に1回だけ、その下は日(`23`)、時刻は2文字下げる。月の目盛りでは年の見出しの下に `10` `11` …
- 列名の行の左には、画面の一番上がどこか(`2026-10`、時刻の行なら `10-23`)を出す
- 日の行には終日の値(曜日など)が並ぶ。時刻の行には時刻つきの予定だけ
- `# nichiji: label` の行があるファイル(曜日など)は自分では行を作らず、ほかの予定がある日の行に添えるだけ。月・年の目盛りでは出さない。この行が無いファイルは、繰り返しの予定だけでも普通に行を作る
- 列の幅は中身に合わせる(短い列は詰める)。幅 70 未満では見出しを短くする

- 未定はいつも一番上
- 終わりの時刻のある予定は、終わりの時刻にも薄く `… end` の行が出る(日付をまたげば次の日の側に)。CSV は1行のまま。選ぶと元の予定を編集する
- メモ欄のある予定には `*` だけが付き、一覧にメモ本文は出さない。選ぶと下の行に出て、Space(`i`)で内容とメモを全文で読める。`/` と `nichiji find` はメモも探す
- `!` は同じファイルの中で重なっている予定、`LATE` は `[reserved]` `[running]` のまま終わりを過ぎた予定
- 日・月・年の目盛りではマスに予定がまとまる(`3: 研修 / 歯医者 / …`)。Enter でマスを開くと1件ずつ選べて、そこで `e` `m` `s` `x` `E` が効く
- 一番下の行はいつも操作のヒント(`?` で全部)

### キー(vim 風)

| キー | 動作 |
|---|---|
| `j` `k` / `gg` `G` / `C-d` `C-u` | 下・上 / 一番古い・新しい日付つきの予定(繰り返しは数えない) / 半画面。表は今の前後を読み、端まで行くと自動で先を読む |
| `h` `l`(Tab) | 列を移る。選んでいる列が書込先 |
| `+` / `-` BS | 目盛りを細かく / 粗く(hour・day・month・year) |
| Enter (`o`) | マスを開いて中の予定を1件ずつ選ぶ(Esc で閉じる) |
| `t` | 今へ |
| `a` | 未定メモ(内容だけ) |
| `A` | 選んでいる日時に追加 |
| Space / `i` | 選んだ予定の内容とメモを全文で読む(`j` `k` で送る、ほかのキーで戻る) |
| `e` / `m` / `s` / `x` | 内容 / メモ欄 / 日時 / 削除。日時を時刻だけ打ち直すと元の長さを引き継ぐ |
| `E` | `$VISUAL` / `$EDITOR` でその行を開く(`+行番号`)。閉じたら読み直し、重なりや読めない日時があれば下の行に出す。日本語をしっかり書くとき(SKK など)はこちら |
| `v` | `[done]` `[canceled]` を隠す / 出す(起動時は隠す。ファイルからは消さない) |
| `/` `n` `N` | 検索 |
| `r` / `?` / `q` | 読み直す / ヘルプ / 終了 |

## 曜日・祝日を並べる

nichiji は曜日の名前を持ちません。`examples/曜日.csv` のような繰り返しのファイルを一緒に開くと、曜日が列として並びます。

```csv
# nichiji: label
w=日,(日)
w=月,(月)
w=火,(火)
```

祝日や六曜なども、同じように CSV を1つ足すだけです。`# nichiji: label` を書いておくと、予定の無い日まで並べずに済みます。

## CSV の書き方

```csv
日時,内容,メモ
2026-10-22 14:00,歯医者,保険証を持っていく
2026-10-22 13:00-15:30,研修
2026-10-23,燃えないゴミ
,いつか本を返す
# コメント行と空行は無視される

*/12/25,クリスマス
1990*/10/24,太郎 \a 歳の誕生日(\y 年生)
w=日 10:00-11:00,教会
w=木 23:00-01:00,夜勤(翌日に続く)
d=1|d=15,給料日
w=土&b=1,バンド練習(最終土曜)
m=1&w=月&a=2,成人の日
w=金&!(m=12&d=25),ポーカー
```

- 1行目の見出しはあってもなくてもよい
- 3列目はメモ欄(無くてよい。2列の行は2列のまま書き戻す)。内容にカンマを含めるときは `"…"` で囲む
- 日時: `2026-10-22 14:00` / `2026-10-22 13:00-15:30`(終わりつき。開始より前なら翌日) / `2026/10/22 9:30` / `2026-10-22`(終日) / 空(未定)
- 画面から入力するときは `10/25 14:00`、`10/25`、`14:00`・`14:00-15:30`(選んでいる日)、`+3`(3日後)、`+3 9:00` も使える
- 繰り返し: 変数 `w` 曜日(`日`〜`土`・`0`〜`6`・`sun`〜`sat`)、`m` 月、`d` 日、`y` 年、`a` 第n週(1〜7日が1)、`b` 最後からn週目、`n` 月の日数。演算子 `=` `!=` `<` `>` `<=` `>=`、`&` `|` `!` `( )`。末尾に ` 10:00` や ` 10:00-11:30` で時刻つき
- `年*/月/日` は毎年。内容の `\a` は年齢、`\y` は起点の年に置き換わる

## 重なりの扱い

TUI・`add`・`set` では重なりを入れられません。エディタで直接書いたときは `nichiji check` か、TUI の `E` から戻ったときの表示で気づけます。始まりと終わりを1行に書くので、間に別の行を挟んで組が崩れることはありません。


1つのファイルは1人の人間か1台の計算機の予定、という前提です。

- 時刻つきの予定は、同じファイルの中で重なると登録・変更できない(`重なる: 10/22 13:00-15:30 研修` と出る)。TUI でも `nichiji add` でも同じ
- 時間帯は「開始以上・終わり未満」。13:00-15:30 のあとに 15:30-16:00 は入る
- 終わりの無い予定は開始の1分だけを占める
- 終日・未定は重なりに数えない(メモ扱い)
- 繰り返しは今日から1年先までを調べる
- エディタで書いてすでに重なっている予定には、赤い `!` が付く

## コマンドで書き換える(set / done)

TUI を開かずに1件を直します。スクリプトや他のプログラムから使う想定です。

- 選び方: `-match 語`(内容の部分一致)、`-at '10/22 14:00'`(開始の日時)。両方指定すると両方に合うもの。2件以上なら候補を出して止まる
- `-status done`: 内容の先頭の `[…]` を書き換える(無ければ足す)
- `-end now` / `-end +30`(今の終わりから30分延ばす)/ `-end 15:20`
- `-d 日時`: 日時を丸ごと替える。`-text`: 内容を丸ごと替える。`-note`: 内容の末尾に ` | …` で足す
- 重なると拒否する。本当に重なってしまったときの記録は `-force`(`!` が付く)
- `done` は `set -status done -end now` の略(終日の予定なら状態だけ替える)

内容の先頭が `[reserved]` か `[running]` のまま終わりの時刻を過ぎた予定には `LATE` が付きます(TUI と `ls`)。
内容が `[done]` か `[canceled]` で始まる予定は、TUI では起動時に隠れます(`v` で出す)。昔の `[予約]` `[実行中]` `[完了]` `[中止]` もそのまま同じ意味で読みます。
`nichiji ls -overdue` で、それだけを取り出せます(既定で30日前から今日まで。1件でもあれば終了コード 1)。`grep LATE` でも探せます。

`ls` は端末に出すときだけ1件を1行に切ります。パイプに流すときは全文を出します(`-full` で常に全文)。

## 通知(notify)

```sh
nichiji notify -watch ~/cal/            # 起動したまま毎分見る
* * * * * nichiji notify ~/cal/         # または cron で毎分
```

- 時刻つきの予定が始まる `-before` 分前(既定 10)と、`[reserved]` `[running]` のまま終わりを過ぎたとき(LATE)に、それぞれ1回だけ知らせる。`[done]` `[canceled]` は知らせない
- 出し先: `-cmd` を指定すればそのコマンドに題と本文を引数で渡す。無ければ `termux-notification`(Termux)→ `notify-send`(Linux デスクトップ)の順に探し、どちらも無ければ端末に出してベルを鳴らす
- 知らせた印は `$XDG_STATE_HOME/nichiji/notified`(既定 `~/.local/state/…`)に残すので、毎分呼んでも二重にならない。2日より古い印は捨てる
