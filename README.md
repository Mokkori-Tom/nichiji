# nichiji

`日時,内容` の2列 CSV だけで動く、端末向けの小さな予定表です。calcurse をもっと素朴にしたもの、形式は [when](https://www.lightandmatter.com/when/when.html) 寄り。

- データは1ファイル2列の CSV。複数のファイル(やフォルダ)をまとめて表示
- 年・週・日(時間軸)・未定の4画面。日表示は 60/30/15 分刻みに切替、終わりの時刻まで帯で表示、画面右上に時計
- クイック登録: 内容だけ打って「未定」に入れ、日時はあとで決める
- 繰り返し予定も2列のまま書ける
- 手を付けていない行・空行・`#` コメントは保存しても元のまま

## 入れ方

```sh
go install github.com/Mokkori-Tom/nichiji@latest
```

Go 製の単一バイナリで、Termux でもそのまま動く想定です。

## 使い方

```sh
nichiji                         # 既定ファイル($NICHIJI_FILE か ~/.local/share/nichiji/nichiji.csv)
nichiji home.csv work.csv       # 最初のファイルが書込先(Tab で切替)
nichiji ~/cal/                  # フォルダ内の *.csv を全部
nichiji ls [-days 14] [-past 0] [-u] [ファイル...]   # 直近の予定を出して終わる
nichiji add 本を返す            # 未定メモを1行追記
nichiji add -d '10/30 19:00' 飲み会
nichiji -now 2026-12-24 ...     # 今日を差し替える(確認用)
```

### キー

| キー | 動作 |
|---|---|
| `d` `w` `y` `u` | 日 / 週 / 年 / 未定 |
| `j` `k` | 上下(年表示では ±1週) |
| `h` `l` | 前後の日・週 |
| `H` `L` | 前後の月(年表示では年) |
| `t` | 今日 |
| `a` | メモ(日時は後で) |
| `A` | 選んでいる日・時間帯に追加 |
| `e` | 内容を編集 |
| `s` / Enter | 日時を決める(年表示の Enter はその日へ) |
| `x` | 削除 |
| `E` | ファイルを `$VISUAL` / `$EDITOR` で開き、閉じたら読み直す |
| `z` | 日表示の刻みを 60 → 30 → 15 分で切替 |
| Tab | 書込先を切替 |
| `r` | 読み直す |
| `?` | ヘルプ |
| `q` | 終了 |

## CSV の書き方

```csv
日時,内容
2026-10-22 14:00,歯医者
2026-10-22 13:00-15:30,研修
2026-10-23,燃えないゴミ
,いつか本を返す
# コメント行と空行は無視される

*/12/25,クリスマス
1990*/10/24,太郎 \a 歳の誕生日(\y 年生)
w=日 10:00-11:00,教会
w=木 23:00-01:00,夜勤(翌日に続く)
d=1|d=15,給料日
w=土&b=1,バンド練習(最終土曜)
m=1&w=月&a=2,成人の日
w=金&!(m=12&d=25),ポーカー
```

- 1行目の `日時,内容` はあってもなくてもよい
- 日時: `2026-10-22 14:00` / `2026-10-22 13:00-15:30`(終わりつき。開始より前なら翌日) / `2026/10/22 9:30` / `2026-10-22`(終日) / 空(未定)
- 画面から入力するときは `10/25 14:00`、`10/25`、`14:00`・`14:00-15:30`(選んでいる日)、`+3`(3日後)、`+3 9:00` も使える
- 繰り返し: 変数 `w` 曜日(`日`〜`土`・`0`〜`6`・`sun`〜`sat`)、`m` 月、`d` 日、`y` 年、`a` 第n週(1〜7日が1)、`b` 最後からn週目、`n` 月の日数。演算子 `=` `!=` `<` `>` `<=` `>=`、`&` `|` `!` `( )`。末尾に ` 10:00` や ` 10:00-11:30` で時刻つき
- `年*/月/日` は毎年。内容の `\a` は年齢、`\y` は起点の年に置き換わる
