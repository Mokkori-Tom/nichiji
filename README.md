# nichiji

`日時,内容,メモ` の CSV だけで動く、端末向けの小さな予定表です。calcurse をもっと素朴にしたもの、形式は [when](https://www.lightandmatter.com/when/when.html) 寄り。

- **1ファイル = 1人か1台**。同じファイルの中で時間が重なる予定は入れられない。複数のファイルを開くと、人(機械)ごとの列が並ぶ
- **予定はどれも、実際に動くための時間枠**。時刻の決まっていない予定(未定・日付だけ)は、決めるまで促し続ける
- 画面は縦に流れる表1つだけ。行が日時、列がファイル。値のある行だけを並べ、時・日・月・年は同じ表の目盛りを変えるだけ
- 曜日や祝日も、ただの CSV として列に並べる(nichiji 自身は曜日の名前を持たない)
- 手を付けていない行・空行・`#` コメントは保存しても元のまま
- 画面・メッセージ・状態の書き方は英語(`[reserved]` `[running]` `[done]` `[canceled]`)。予定の中身は何語でもよい
- Go 製の単一バイナリ。Termux でも動く

## 入れ方

```sh
go install github.com/Mokkori-Tom/nichiji@latest
```

## 使い方

```sh
nichiji 曜日.csv tom.csv hana.csv    # TUI。列はこの順。書込先の既定は label のファイルを飛ばした最初のもの
nichiji ~/cal/                       # フォルダ内の *.csv を全部(ファイル名の順)
nichiji ls [-days 14] [-past 0] [-u] [-memo] [ファイル...]   # 直近の予定を出して終わる(メモは * だけ、-memo で本文も)
nichiji ls -overdue [ファイル...]    # 終わりを過ぎた [reserved] [running] だけ。あれば終了コード 1
nichiji check [ファイル...]          # 手で書き換えたあとの確認(下記)。あれば終了コード 1
nichiji find 歯医者 [ファイル...]     # 全期間・未定・繰り返しの内容とメモを探す(ファイル名:行番号 付き)。無ければ終了コード 1
nichiji add 本を返す                 # 未定で1行追記
nichiji add -d '10/30 19:00-21:00' -m '駅前の店' 飲み会
nichiji set -f r.csv -match 語 -status running -end +30   # 1件を書き換える(下記)
nichiji done -f r.csv -match 語 -note '結果: x.out'      # 完了にして終わりを今に
nichiji free [-len 60] [-from 9:00] [-to 18:00] [-days 14] tom.csv hana.csv   # 全員が空いている枠
nichiji notify [-before 10] [-cmd CMD] [-watch] [ファイル...]   # 通知(下記)
nichiji -now '2026-12-24 10:00' ...  # 今を差し替える(確認用)
```

ファイルを指定しなければ `$NICHIJI_FILE`、無ければ `~/.local/share/nichiji/nichiji.csv` を使います。`add` `set` `done` の書込先は `-f` で指定します。

## 画面

```
nichiji hour  2026-10-23  no time:2  now 13:30
        曜日 tom          hana
undated      本を返す
2026-10-23
        (金)
  09:00      ┌定例
  10:00      └定例
  13:00      ┌研修 *
  14:00      │            来客
  15:00      └研修
  18:00                   電話
2026-10-24
        (土) 燃えないゴミ
tom  2026-10-23 13:00-15:00  研修  | memo: 会議室B
j/k move h/l column +/- scale Enter open Space memo u no-time f free …
```

- 見出し: 目盛り、画面の一番上の位置(`2026-10-23`、月の目盛りなら年)、時刻の決まっていない予定の数(赤)、今の時刻。幅が広ければ `done:hidden` なども出る
- 日付は日付だけの行に書き、その下に終日の値(曜日・終日の予定)と、2文字下げた時刻の行が並ぶ(khal や gcalcli のアジェンダと同じ形)
- 終わりの時刻のある予定は `┌` で始まり、終わりの時刻の行に `└` が出る。間に別の行が挟まれば `│` でつなぐ。日付をまたぐ予定は次の日の側に `└` が出る。CSV は1行のまま(`23:00-01:00`)で、`└` の行を選ぶと元の予定を編集する
- 日・月・年の目盛りは時刻を書かず、1件1行で縦に並べる。月・年では同じ予定(繰り返しなど)を1行にまとめて `週次ミーティング x4` と回数を付ける
- 未定はいつも一番上
- メモのある予定には `*` だけが付き、一覧にメモの本文は出さない。選ぶと下の行に出て、Space で全文を読める
- `!` は同じファイルの中で重なっている予定、`LATE` は `[reserved]` `[running]` のまま終わりを過ぎた予定
- 列の幅は中身に合わせる(短い列は詰める)。幅 70 未満では見出しを短くする
- 罫線(`┌ │ └`)は幅1として数える。日本語フォントの設定で罫線を幅2で描く端末なら `NICHIJI_AMBIGUOUS_WIDE=1`
- 一番下の行はいつも操作のヒント(`?` で全部)

### キー(vim 風)

| キー | 動作 |
|---|---|
| `j` `k` / `gg` `G` / `C-d` `C-u` | 下・上 / 一番古い・新しい日付つきの予定(繰り返しは数えない) / 半画面。表は今の前後を読み、端まで行くと先を読む |
| `h` `l`(Tab) | 列を移る。選んでいる列が書込先 |
| `+` / `-` BS | 目盛りを細かく / 粗く(hour・day・month・year) |
| `t` | 今へ |
| Enter (`o`) | マスを開いて、中の予定を1件ずつ日時付きで選ぶ(Esc で閉じる) |
| Space / `i` | 選んだ予定の内容とメモを全文で読む(`j` `k` で送る、ほかのキーで戻る) |
| `u` | 時刻の決まっていない予定へ移る。全員分を日付の近い順に、押すたびに次へ(未定は最後)。時刻は移った先で `s` |
| `f` | 選んでいる列の人が次に空いている時間(15分以上)へ移る。続けて押すと次の空き、そこで `A` を押すと空きの始まりに足す。夜中も空きに数える |
| `a` | 未定で追加(内容だけ) |
| `A` | 選んでいる日時に追加 |
| `e` | 内容を書き換える |
| `m` / `M` | メモを1行の入力欄で / エディタで書き換える。エディタなら普通に改行でき、SKK などもエディタのまま。改行のあるメモは `m` でもエディタが開く |
| `s` | 日時を書き換える。日付だけ・時刻の無い繰り返しなら今の日時が入った状態で開くので、時刻を足すだけ。時刻だけ打ち直すと元の長さを引き継ぐ |
| `x` | 削除 |
| `E` | ファイルを `$VISUAL` / `$EDITOR` で、選んだ予定の行から開く。閉じたら読み直し、重なりなどがあれば下の行に出す |
| `v` | `[done]` `[canceled]` を隠す / 出す(起動時は隠す。ファイルからは消さない) |
| `/` `n` `N` | 検索(内容とメモ) |
| `r` / `?` / `q` | 読み直す / ヘルプ / 終了 |

## 時刻の決まっていない予定

この予定表の予定はどれも、実際に動くための時間枠です。燃えないゴミも、出しに行く時間を取ります。次のものは時刻が決まるまで促し続けます。

- 未定(日時が空)
- 日付だけの予定(`2026-10-24,燃えないゴミ`)
- 時刻の無い繰り返し(`d=1,家賃の振込`)

TUI では見出しに `no time:3` を出し、起動時にも知らせます。`u` で順に移って `s` で時刻を足します(`2026-10-24 7:30-7:40`、`d=1 9:00-9:10`)。`ls` は一番下に、`notify` は1日1回知らせます。`# nichiji: label` のファイルと `[done]` `[canceled]` は対象外です。

## 曜日・祝日を並べる

nichiji は曜日の名前を持ちません。`examples/曜日.csv` のような繰り返しのファイルを一緒に開くと、曜日が列として並びます。

```csv
# nichiji: label
w=日,(日)
w=月,(月)
w=火,(火)
```

`# nichiji: label` の行があるファイルは、自分では行を作らず、ほかの予定がある日に添えるだけになります。月・年の目盛りでは列ごと隠れ、時刻を決める促しの対象にもなりません。この行の無いファイルは、繰り返しの予定だけでも普通に行を作ります。祝日や六曜なども、同じように CSV を1つ足すだけです。

## CSV の書き方

```csv
日時,内容,メモ
2026-10-22 14:00,歯医者,"保険証を持っていく
会計は現金のみ"
2026-10-22 13:00-15:30,研修
2026-10-23 7:30-7:40,燃えないゴミ
,いつか本を返す
# コメント行と空行は無視される

*/12/25 19:00-21:00,クリスマス
1990*/10/24 19:00,太郎 \a 歳の誕生日(\y 年生)
w=日 10:00-11:00,教会
w=木 23:00-01:00,夜勤(翌日に続く)
d=1|d=15 9:00-9:10,給料の確認
w=土&b=1 14:00-17:00,バンド練習(最終土曜)
m=1&w=月&a=2,成人の日
w=金&!(m=12&d=25) 20:00,ポーカー
```

- 1列目 日時、2列目 内容、3列目 メモ(無くてよい。2列の行は2列のまま書き戻す)。見出しの行(`日時,内容`)はあってもなくてもよく、何行目にあっても見出しとして扱う
- CSV のルール(RFC 4180)どおり、カンマ・改行・`"` を含むセルは `"…"` で囲む。メモの改行はセルの中にそのまま入る(`M` でエディタに書けば nichiji が囲んで書く)
- 4列以上ある行は、カンマの囲み忘れの疑いとして `check` が知らせる(3列目以降をメモとして読む)
- 日時: `2026-10-22 14:00` / `2026-10-22 13:00-15:30`(終わりが始まり以前なら翌日) / `2026/10/22 9:30` / `2026-10-22`(日付だけ) / 空(未定)
- 画面やコマンドから入力するときは `10/25 14:00`、`10/25`、`14:00`・`14:00-15:30`(選んでいる日)、`+3`(3日後)、`+3 9:00` も使える
- 繰り返し: 変数 `w` 曜日(`日`〜`土`・`0`〜`6`・`sun`〜`sat`)、`m` 月、`d` 日、`y` 年、`a` 第n週(1〜7日が1)、`b` 最後からn週目、`n` 月の日数。演算子 `=` `!=` `<` `>` `<=` `>=`、`&` `|` `!` `( )`。末尾に ` 10:00` や ` 10:00-11:30` で時刻つき
- `年*/月/日` は毎年。内容の `\a` は年齢、`\y` は起点の年に置き換わる
- 内容の先頭の `[reserved]` `[running]` はまだ終わっていない予定、`[done]` `[canceled]` は済んだ予定(昔の `[予約]` `[実行中]` `[完了]` `[中止]` も同じ意味で読む)

## 重なりの扱い

1つのファイルは1人の人間か1台の計算機の予定、という前提です。

- 時刻つきの予定は、同じファイルの中で重なると登録・変更できない(`overlaps: 10/22 13:00-15:30 研修` と出る)。TUI・`add`・`set` のどれでも同じ。別のファイルどうしは重なってよい
- 時間帯は「開始以上・終わり未満」。13:00-15:30 のあとに 15:30-16:00 は入る
- 終わりの無い予定は開始の1分だけを占める
- 日付だけ・未定の予定は、時刻が決まるまで重なりの対象外(代わりに時刻を決めるよう促す)
- 繰り返しは今日から1年先までを調べる
- エディタで直接書いて重なった予定には `!` が付く。`nichiji check` と、TUI の `E` から戻ったときの確認でも知らせる

## 手で書き換えたあとの確認(check)

`nichiji check` は次のものを、ファイル名と行番号付きで出します。1件でもあれば終了コード 1。TUI でも `E` から戻ったときに同じ確認をします。

- `unreadable date`: 読めない日時
- `overlaps`: 同じファイルの中の重なり
- `LATE`: `[reserved]` `[running]` のまま終わりを過ぎた予定(30日前まで)
- `broken?`: 1件が何行にもまたがり、その中に予定らしい行がある(普通の `sort` でセルの中の改行が分断されたときなど)。TUI も起動時に警告する
- `N columns`: 4列以上ある行

## 行の並べ替え

表示は日時で並べ直すので、ファイルの中の順番は自由です(保存しても順番は変えない)。同じ日の終日の予定どうし・未定どうしは、書いた順に並びます。

ファイルそのものを並べ替えるなら、CSV を分かるツールを使ってください。セルの中の改行を壊しません。

```sh
# miller (Go 製): 見出し無し・2列と3列の混在・# コメントもそのまま(コメントは先頭に集まる)
mlr --csv -N --allow-ragged-csv-input --pass-comments sort -f 1 tom.csv > sorted.csv
```

普通の `sort` は行ごとに並べ替えるので、改行を含むセルが分断されます。そうなったら読み込みでエラーになるか、`check` が `broken?` として知らせます。

## コマンドで書き換える(set / done)

TUI を開かずに1件を直します。スクリプトや他のプログラムから使う想定です。

- 選び方: `-match 語`(内容の部分一致)、`-at '10/22 14:00'`(開始の日時)。両方指定すると両方に合うもの。2件以上なら候補を出して止まる
- `-status done`: 内容の先頭の `[…]` を書き換える(無ければ足す)
- `-end now` / `-end +30`(今の終わりから30分延ばす)/ `-end 15:20`
- `-d 日時`: 日時を替える(時刻だけ打ち直すと元の長さを引き継ぐ)。`-text`: 内容を替える。`-m`: メモを替える。`-note`: 内容の末尾に ` | …` で足す
- 重なると拒否する。本当に重なってしまったときの記録は `-force`(`!` が付く)
- `done` は `set -status done -end now` の略(日付だけの予定なら状態だけ替える)

`nichiji ls -overdue` で LATE の予定だけを取り出せます(既定で30日前から今日まで。1件でもあれば終了コード 1)。`grep LATE` でも探せます。`ls` は端末に出すときだけ1件を1行に切り、パイプに流すときは全文を出します(`-full` で常に全文)。

## 空きを探す(free / f)

- `nichiji free`: 読み込んだ全員が `-len` 分(既定 60)以上空いている枠を、1日の `-from`〜`-to`(既定 9:00〜18:00)で `-days` 日先(既定 14)まで探す。始まりは5分単位に切り上げる
- TUI の `f`: 選んでいる列の人だけについて、今から先で15分以上の空きへ移る。こちらは1日じゅう(夜中も)を探す
- どちらも、日付だけ・未定の予定は時間を塞がない扱い

## 通知(notify)

```sh
nichiji notify -watch ~/cal/            # 起動したまま毎分見る
* * * * * nichiji notify ~/cal/         # または cron で毎分
```

- 時刻つきの予定が始まる `-before` 分前(既定 10)と、`[reserved]` `[running]` のまま終わりを過ぎたとき(LATE)に、それぞれ1回だけ知らせる。`[done]` `[canceled]` は知らせない
- 時刻の決まっていない予定があれば、1日1回「3 entries have no time: schedule them」と知らせる
- 出し先: `-cmd` を指定すればそのコマンドに題と本文を引数で渡す。無ければ `termux-notification`(Termux)→ `notify-send`(Linux デスクトップ)の順に探し、どちらも無ければ端末に出してベルを鳴らす
- 知らせた印は `$XDG_STATE_HOME/nichiji/notified`(既定 `~/.local/state/…`)に残すので、毎分呼んでも二重にならない。2日より古い印は捨てる
